# Detecção de Rostos em Imagens

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Projeto em Python que faz a detecção de rostos em imagens.

---
## 📚 Aprendizados
- Uso da biblioteca opencv
- Aplicação do Haar Cascade
- Deteccção de rostos aplicado a imagens

## ⚙️ Funcionalidades
- Detecção o rosto presente em uma imagem qualquer

## 🛠️ Stack
- Python
- Biblioteca opencv

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/PenelopeFarias745/face-detect-on-image
```

2. Abra o arquivo no VSCode e execute-o.
